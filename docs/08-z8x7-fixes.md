# z8x7：应用退出与每日壁纸

**后续实机反馈：壁纸看起来已纠正，但应用退出仍返回极米桌面。TASK_ON_HOME 调整未解决本机问题，正在采集任务栈诊断，不应向其他人宣称退出行为已修复。**

用户报告 QQ 音乐、极米任意门等应用退出后回到极米桌面，但按实体 Home 仍回简洁桌面。这说明当时默认 HOME 仍有效，不能把问题归因于默认桌面设置丢失。

首页卡片和应用库的启动 Intent 增加 TASK_ON_HOME，配合 NEW_TASK 指示 Android 在应用任务结束后返回 Home；保留原有任务复用，不清数据、不强制停止应用。Android 8 AOSP ActivityStarter 的 updateTaskReturnToType 明确处理此标记，但极米固件及应用自己主动跳转仍可能不同，因此此修正为待实机验证的兼容调整，不能保证覆盖所有应用退出行为。

壁纸的问题有直接证据：2026-10-24 的 Bing 首图 wp=false，而 23 日“两只狼”图片可用。旧代码拒绝不可用首图后继续使用缓存，用户看到“暂未获取到新壁纸”。

新版请求最近 8 张，只选择 wp=true 且 URL 有效的图片；优先选择不同于缓存的最近可用图片。若今天首图不可用，会显示近期替代图片，不把旧图伪装成今日来源。设置分别记录下载成功日期和图片日期，并显示替代提示。升级时清除旧重试时间/完成日期以立即重查，但保留已下载缓存；断网或全部图片不可用时继续保留缓存。

当天真实接口测试成功选择并下载 22 日替代图（1920×1080）。桌面可见时每天检查和失败退避逻辑保留；这不承诺每日内容都是当天新发布的照片。既有与新增共 214 项 JVM 测试通过，lint 与签名校验通过。

安装后验收：

1. 覆盖安装 z8x7，先按实体 Home 回简洁桌面。
2. 从简洁桌面打开 QQ 音乐，使用应用内退出/Back 退出，观察返回页面；再测任意门与应用库启动。
3. 联网停留在简洁桌面片刻，检查图片和设置里的图片日期/替代状态。
4. 将结果记录为实机结果。若退出仍进极米桌面，不连续重复设置默认桌面；继续核实应用主动跳转或厂商任务栈行为。

## 2026-10-24 后续诊断

完整的 12 次任务栈采样显示：简洁桌面位于 HOME 栈顶部，QQ 音乐的任务返回目标也确实为 HOME；QQ 音乐退出期间，简洁桌面和诊断工具的任务同时从记录中消失，原桌面任务继续显示。采集后默认 HOME 仍解析为简洁桌面。因此不能再将此问题简单归因于缺少 TASK_ON_HOME，也不能声称已确定是某个厂商清理服务造成。

后续只读事件采集返回 `logcat read failure`，未获得进程退出原因。两个 global 设置键返回 null，不能据此推断实际进程限制。旧诊断工具曾把脚本结束误报为采集完整；已修正判定，后续需读取实际后台策略。临时维护目录恢复和服务关闭均通过检查。诊断 APK 仅用于本机排查，不属于本仓库的两个正式安装包。

### 后台策略基线

后续读取系统实际配置得到 `max_cached_processes=2`、`CUR_MAX_CACHED_PROCESSES=2`、`CUR_MAX_EMPTY_PROCESSES=1`。同次采样 `MemAvailable=795112 kB`，简洁桌面进程未列出，`mHomeProcess` 指向极米桌面，但默认 HOME 解析仍是简洁桌面。这个快照不是 QQ 音乐退出瞬间，不能单凭它确定清理原因或排除当时的内存压力。

已准备缓存上限 8 的可撤销试验：保存原始 `activity_manager_constants` 值，仅替换该键中的 `max_cached_processes` 项，保留其他参数；原先不存在该设置时，恢复操作删除该设置。若配置被外部修改则拒绝覆盖。试验可能增加后台内存占用，尚未验证其对应用退出行为的效果，不属于正式推荐配置。

### 缓存试验结果：配置写入未改变运行上限

试用工具读回设置值成功，但紧接着读取 ActivityManager 的 `max_cached_processes` 与 `CUR_MAX_CACHED_PROCESSES` 仍为 2，并未升至 8。用户随后反馈应用退出仍返回极米桌面。因此该试验未改变已观察到的运行策略，不能用此结果排除后台清理因素，也不能宣传“缓存上限 8 已生效但无效”。已要求使用工具的“恢复原后台设置”撤销设置写入；恢复是否完成需后续报告确认。未确认恢复前保留工具与备份数据。

首次恢复报告返回 `change=conflict`，因此不能宣称已撤销试验；临时维护清理通过。恢复工具已修正为在维护上下文直接核对当前值：等于已保存原值时不写入，等于已保存试用值时恢复原值，其他值拒绝覆盖。该修正仍需实机恢复报告确认；不应删除备份或卸载工具。

### 恢复已验证

修正版恢复工具的实机报告包含 `Deleted 1 rows`、`change=verified`、`restore=restored-original`：试验前该 global 设置不存在，本次删除试验新增的设置并读回确认。实际缓存上限恢复检查仍为 2，默认 HOME 仍解析为简洁桌面；维护目录恢复及服务关闭检查通过。本次缓存试验已撤销，应用退出返回原桌面的问题仍未解决。
