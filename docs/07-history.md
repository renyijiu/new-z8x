# 本次完整处理过程

## 1. 确认目标与设备

目标是减少桌面广告、改善操作体验、处理预装应用与开机广告问题。首先确认 NEW Z8X、Android 8.0.0 与完整固件版本，再以 cleanyourtv 为基础研究。最终完成的是新桌面与默认 HOME 切换；开机广告与系统应用精简没有执行，避免将目标误写成成果。

## 2. 无线安装路径

发现本机仅有 Samba、DLNA 与投屏。DLNA/投屏不适合作为 APK 安装文件通道，因此尝试 Samba。macOS 原生共享与匿名访问在电脑侧可用，但投影仪持续报密码错误；最终以 Docker Samba 的独立账号、旧协议兼容、只读 APK 共享完成传输。原生共享曾作临时调整，随后恢复；后续传输使用限时容器，不依赖修改原生共享。

## 3. ADB 路线未通过

通过开启器打开网络调试后，电脑连接停在授权，投影仪没有确认弹窗。多次等待不等于授权成功。关闭开启器的开机恢复，使用关闭工具并正常重启，检查端口关闭。没有取得已授权 ADB shell，没有借此批量卸载应用。

## 4. 桌面从能安装到适合投影仪

- 初版仅提供 Android TV Leanback 入口，安装后在极米普通应用列表中看不到；z8x1 加入 LAUNCHER。
- z8x2 增加 Bing 每日壁纸与离线回退，改系统字体、调整滚动与焦点动画。
- z8x3 调整应用卡片与 Dock，探索设置入口。
- z8x4 按用户要求保留 Wi-Fi 按钮但移除备用跳转路线。
- z8x5 从本机系统设置应用清单确认 SettingService，直接打开设置侧边栏，避开只有一个 Setting 按钮的 MockActivity 中间页，用户确认设置与 Back 可用。
- z8x6 增加“返回极米桌面”。用户报告第一次曾跳回简洁桌面，后续正常；重启后首次点击也正常。原因未确定，未额外编造修复。

## 5. 普通默认桌面设置受限

系统的默认桌面页面不支持，Home 直接回极米桌面；应用管理也没有可用的清除默认设置入口。因此单纯安装新桌面无法接管 Home。

## 6. 由只读核对到临时 root 验证

参考 xgimi-clean 的 NEW Z6X 维护通道研究，但先核对本机服务定义、脚本、平台、目录与挂载信息。取得用户明确授权后尝试最小临时验证。早期遇到脚本 fd 未关闭、回执权限时间窗和 SSH 子进程清理问题；通过修正和独立检查，最终取得 UID 0 与 root 所有回执的双重证据，清理完成且 22/5555 拒绝连接。

没有照搬参考项目中永久化 root、修改系统分区或批量停用软件的完整路线。没有安装持久 root，也没有写 ADB 密钥。

## 7. 设置 HOME 与确认

使用临时权限执行 set-home-activity。早期只带 HOME 的查询把 FallbackHome 算进候选集合，导致判断异常；改为 HOME + DEFAULT。还发现部分日志会在设置成功后不完整，因此以清理后的真实解析结果为准。最终系统解析为简洁桌面，用户按实体 Home 确认成功。

## 8. 整理成独立切换器

去掉电脑 HTTP 接收器、回执 token、一次尝试锁和历史 root 记录依赖，加入兼容性预检、本地 journal、前台执行、恢复检查。提供默认简洁、默认极米、临时打开三个入口。发布 1.0 并完成构建/签名/模拟测试；独立双向切换和异常中断恢复仍按设备页标记为待明确实机确认。

## 9. 最终分发与维护

仅保留两款最终 APK 及对应源码，历史诊断 APK 不作为新使用者的必经步骤。Samba 完成传输后关闭；保留原极米桌面和关键系统组件。若升级固件，重新核对兼容性，不强行沿用本机指纹。
