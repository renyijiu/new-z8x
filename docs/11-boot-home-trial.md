# z8x11 开机进入简洁桌面试验

状态：源码和自动检查完成后提供测试 APK；开机行为待 NEW Z8X 实机验证。

之前 ReturnGuard 只在简洁桌面启动外部应用时设定待返回标记。开机直接显示原桌面没有这个标记，因此即便服务存活也不会跳转。

本版利用现有返回兼容服务，在每次完整开机的前 3 分钟内允许一次开机返回。必须同时满足兼容开关开启、默认桌面为简洁桌面、尚未进入简洁桌面或主动放行原桌面。服务首次连接时使用上游已有的透明 ProbeActivity，让已经显示的窗口重新发出事件；仅匹配极米 HomeActivity 时跳转，不匹配 HDMI 或其他应用。

进入简洁桌面或主动放行极米桌面会记录本次开机已处理，避免设置里的“返回极米桌面”被拦截。没有新增开机广播、网络轮询或常驻前台服务，不更改默认桌面或系统白名单。开关关闭时不开启此功能。

安装后先确认应用退出返回、主动返回极米桌面和 Home 键仍正常；然后完整关机开机测试。系统可能先短暂显示极米桌面再跳转，本版不修改系统启动动画。如果无障碍服务在开机 3 分钟后才连接，会跳过自动进入；不在日常使用中突然抢回桌面。

## 实机反馈与回退

用户安装 z8x11 完整断电重启后仍进入极米桌面，兼容服务显示等待连接；手动重连后乐播退出也回到极米桌面。尚未读取此轮设备配置和断开时刻，不能断定是新逻辑导致，也不能声称白名单已被覆盖。

z8x12 撤回 z8x11 开机探测和开机待返回状态，恢复 z8x10 返回逻辑，仅提高版本号以便覆盖安装。恢复后的设备表现待验证，开机自动进入问题未解决。
