# z8x13：白名单只读保护后的开机恢复试验

用户已确认只读保护后完整开机、退出应用可回简洁桌面，但首次开机仍为极米首页。z8x12 本身撤回了开机跳转，因此从该已验证返回逻辑单独补充开机恢复。

新增 RECEIVE_BOOT_COMPLETED 和不对普通应用导出的 BootHomeReceiver，仅处理系统 BOOT_COMPLETED。只在应用返回兼容开关已开启、默认 HOME 是简洁桌面、完整启动前3分钟、当次尚未进入过简洁桌面时尝试恢复自己的无障碍服务；保留其他服务列表。若用户关闭兼容开关或切换默认桌面，不自动启动。

服务连接时借用上游 ProbeActivity 触发前台窗口事件，仅精确匹配极米 HomeActivity 才跳转。探测每次启动最多一次，进入简洁桌面或主动放行原桌面后记录已处理；晚到的服务连接跳过，避免日常使用时抢回桌面。不修改白名单或原桌面组件，不新增定时轮询或联网服务。系统可能短暂显示极米再跳转，此方案不修改启动动画。

设置的返回兼容状态增加“开机记录”：尚未收到开机通知、收到通知恢复服务、服务已连接等待首页、已请求进入或错误信息。即便固件拦截开机通知，也能保留可定位的状态。

验证：覆盖安装后打开简洁桌面，确认版本2.6-z8x13、兼容已连接；完整关机断电再开机。观察首次桌面和是否自动跳转，再测试乐播退出、Home键、主动返回极米桌面。实机结果待用户测试。宿主机单元测试/静态检查不证明该固件会交付开机广播。
