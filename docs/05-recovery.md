# 恢复与故障排查

## 切换器提示清理未完成

1. 保持投影仪开机，等待正在执行的事务结束。
2. 点“恢复检查”。它只读取本切换器私有 journal，清理对应 run 的文件并复查。
3. 若仍失败，先正常重启，再打开切换器恢复检查。重启可结束临时进程，但**不保证删除遗留 params 或目录**，不能以重启代替清理核验。
4. 未确认清理前不要清除切换器数据或卸载它，否则会丢失其事务记录。不要手动删除 `/data/ssh`、主机密钥或不明文件。
5. 若文件来自旧诊断工具，新切换器不应接管；应保留旧工具与日志，用原来的恢复流程处理。

本切换器没有自己的操作记录时，“恢复检查”提示没有记录是正常的。它不是通用 SSH/ADB 关闭器。

## 如何确认维护通道关闭

应用内成功状态结合了服务属性、sshd 进程、目录还原与本机端口检查。电脑可选做外部复核：

```sh
python3 tools/check_ports.py <投影仪局域网IPv4>
```

工具仅连接并关闭 TCP 22、5555，不发送登录信息、不尝试提权。`REFUSED` 表示该次 TCP 连接被拒绝；`OPEN` 表示可连接；`UNKNOWN` 表示超时/网络不可达等，**不能当作已关闭**。外部端口检查不能替代应用对目录和服务状态的检查。

## 切回极米桌面/卸载

1. 打开“极米桌面切换”，点“默认极米桌面”。
2. 等待完成与清理关闭提示，按实体 Home 验证确实进入原桌面。
3. 再正常重启检查一次。
4. 确认已不依赖新桌面后，才卸载简洁桌面；切换器无待清理事务时也可卸载。

“简洁桌面设置 → 返回极米桌面”只临时打开原桌面，不构成卸载前的默认桌面回退。

## 常见现象

| 现象 | 处理 |
|---|---|
| 安装成功但应用列表看不到 | 确认使用 z8x13；早期仅有 Leanback 启动入口，本最终版包含普通 LAUNCHER |
| 点选择默认桌面提示不支持 | 此固件不提供标准页面，使用独立切换器 |
| 维护脚本/固件不兼容 | 停止；记录完整版本，不修改哈希或删掉预检 |
| ADB/SSH 原来已开或存在维护文件 | 先结束已有会话；不要让新切换器接管未知状态 |
| 设置中出现只有 Setting 的中间页 | 确认版本为 z8x13；最终版使用已验证 SettingService 打开侧边栏 |
| Wi-Fi 按钮不可用 | 从投影仪系统设置侧边栏进入网络设置，最终版按要求不显示备用入口 |
| 首次点返回极米桌面跳回简洁桌面 | 原机安装后曾出现一次；后续及重启后正常，原因未定位。若反复出现，记录版本、是否冷启动、按键与实际页面后排查，不将其描述为已修复的确定原因 |
| 壁纸无照片 | 确认每日壁纸选项与网络；可重选触发重试，断网/下载失败有缓存或渐变回退 |
| 包签名不一致 | 核实安装包来源；自行签名不能覆盖发布签名，不要直接卸载正在使用的默认桌面 |

## 不在本方案中做的处理

不提供预装应用一键卸载清单，不禁用原桌面，不清空整个维护目录，不改系统分区或安装开机 root。遥控器、蓝牙、对焦、梯形校正、HDMI、投屏、语音、系统设置和升级组件应保留，除非另做针对性验证。

## 后台保护与ADB回退

卸载桌面前，除恢复默认极米桌面外，还应按 [最终配置与临时ADB](13-adb-and-final-setup.md) 解除 sys_admin_pkg.json 只读保护并恢复原配置/权限。保留设备上的原始备份直到恢复读回成功。只卸载桌面或诊断工具不会恢复文件权限，也不等于关闭ADB。
