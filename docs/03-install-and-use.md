# 安装、切换与日常使用

## 1. 安装前核对

对照设备页的型号和完整固件。先记录原设置，确认原极米桌面、系统设置和文件管理能打开。不要先删除或停用原桌面。

电脑在仓库根目录运行 `python3 tools/verify.py`，应显示两个 APK 校验通过。通过 Samba 进入安装包目录。

如果过去使用过 ADB 开启器，先关闭它的“开机自动恢复”和调试开关，再正常重启。**卸载开启器本身不等于关闭调试。**本独立切换器要求 ADB/SSH 原先关闭，不需要安装或开启 ADB 开启器；如果预检提示已有维护会话，先处理该会话，不反复尝试提权。

## 2. 先安装简洁桌面

安装 `02-clean-home-z8x13.apk`。若系统询问是否允许当前文件管理来源安装，按系统提示允许。这个旧系统已实测可以从 Samba 安装；其他设备没有安装入口时不要改固件强行绕过。

安装后选择“打开”，或在应用列表找到“主屏幕”。先检查方向键、OK、返回与常用应用启动。此时 Home 仍回原桌面并不表示安装失败：安装桌面和选择系统默认桌面是两件事。

覆盖同一签名的旧版通常保留布局及壁纸选择；不要为升级先清除数据。若提示签名不一致，先确认旧包来源，不要盲目卸载当前唯一可用的默认桌面。

## 3. 安装极米桌面切换

安装 `15-z8x-home-switch-v1.apk`，在应用列表打开“极米桌面切换”。这是独立应用，不会覆盖旧的“极米临时权限验证”。

- **默认简洁桌面**：设为 com.gathin.tvhome。
- **默认极米桌面**：设回 com.xgimi.home。
- **临时打开极米桌面**：只打开原桌面，不改默认选择。
- **恢复检查**：用于本切换器自己的待清理事务。

点击“默认简洁桌面”后等待提示完成。可能需要约一两分钟，期间保持投影仪开机，不重复点击、不强制停止。成功结果必须同时满足目标桌面读回正确和维护清理验证通过。

若显示不兼容、目录已有维护文件、端口已开放或清理未完成，转到故障排查；不要删除检查逻辑、删除未知文件或安装历史测试包来绕过。

## 4. 安装后的验收顺序

1. 等待切换完成且提示维护通道已关闭，按实体 Home，确认进入简洁桌面。
2. 在“简洁桌面设置 → 投影仪系统设置”打开侧边栏，按 Back 确认返回合理。
3. 点“简洁桌面设置 → 返回极米桌面”，确认进入原桌面，再按 Home 回简洁桌面。
4. 在切换器中设“默认极米桌面”，按 Home 验证；再设“默认简洁桌面”并验证。
5. 正常重启，联网后按 Home，再测试临时返回入口。
6. 按实际用途检查音量、遥控器、HDMI、投屏、语音、自动对焦和梯形校正；本记录未替所有人逐项验收这些功能。

第 4、5 项应由新使用者实际完成。原机前序方案验证成功，不替代独立 APK 在另一台机器上的验收。

## 5. 简洁桌面功能

- 壁纸：默认“每日壁纸（联网）”，桌面显示时检查 Bing，最新图片不可用或仍是缓存图片时从近期可用图片中选替代图，设置显示图片日期；成功后同日复用缓存；断网使用已有缓存，首次无缓存使用内置渐变。失败至少隔一小时重试；重新选择每日壁纸可重试。Bing 内容不保证每天都是风景。
- 联网说明：桌面新增 INTERNET 权限，用 HTTPS 请求 Bing 壁纸；无常驻下载服务，不上传应用清单。切换器的 INTERNET 权限仅供本机端口检查，不下载命令。
- 视觉：使用系统 sans-serif、较缓和滚动、无普通焦点缩放/回弹；Dock 可选 30/50/70/100% 不透明度。应用自带黑色横幅仍可能保留黑色。
- Wi-Fi：保留按钮，只尝试直接打开无线设置；不再跳到难看的备用设置页。此固件不支持直达时，从“投影仪系统设置”的侧边栏进入网络设置。
- “选择默认桌面”是上游标准系统入口，该固件可能仍提示不支持。**实际切换请使用独立“极米桌面切换”应用。**
- “返回极米桌面”是普通应用跳转，不需要执行临时 root，不改变默认桌面。

## 6. 最后保留什么

保留简洁桌面和极米桌面切换，并保留系统原桌面与投影功能相关组件。确认各旧工具的维护会话都已结束后，可卸载本次旧 ADB 开启器、关闭调试工具、临时验证/诊断 APK。新切换器的恢复按钮只认识自己的事务，不能保证清理旧工具遗留文件。

安装包文件可以删除，不影响已安装应用；建议在电脑保留本仓库用于重装。不要在简洁桌面仍为默认时直接卸载它，先切回极米默认并按 Home 验证。

## 7. 当前固件的后台与开机设置

上述日常APK安装后，还需要一次性授予兼容服务权限及后台白名单保护，才能复现本机最终效果。请继续阅读 [最终配置与临时ADB](13-adb-and-final-setup.md)，不要仅安装APK就认定已经完成。长期保留策略原始备份，删除诊断应用前先核对临时调试全部关闭。
