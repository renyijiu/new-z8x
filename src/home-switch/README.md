# 极米桌面切换 1.0

专供本次已验证的 NEW Z8X：Android 8.0.0 / API 26，device ironman，hardware m7221，incremental v12.15.214。应用包名 local.projector.homeswitch，与之前的诊断工具独立。

## 使用

安装后打开“极米桌面切换”。“默认简洁桌面”和“默认极米桌面”更改系统默认 HOME；“临时打开极米桌面”只打开原桌面。切换完成后按遥控器 Home 验证。简洁桌面 com.gathin.tvhome 与极米桌面 com.xgimi.home 均须已安装启用。

操作使用本机厂商维护通道执行固定的 set-home-activity 命令，随后关闭通道。不是普通应用直接修改系统权限，也不安装持久 root。无需电脑、互联网或接收回执服务；INTERNET 权限仅用于本机 127.0.0.1 的调试端口状态检查。

操作记录仅在应用私有目录保存。若被强制停止或中途断电，再打开应用后点“恢复检查”；未完成清理时禁止新切换。恢复未完成前不要清除本应用数据或卸载，以免丢失清理记录。切换失败时尝试回到之前的已知桌面；原状态为桌面选择框时以极米桌面作为回退目标。结果页以实际默认桌面读取值和清理结果为准。

兼容性检查包括固件、维护脚本 SHA-256、init 服务定义、现有维护会话、目录元数据及两个桌面入口。不兼容时停止。仅处理本次临时文件；不修改系统分区，不删除或禁用原桌面，不新增开机启动服务、ADB 密钥或常驻调试入口。

## 验证边界

固定切换命令及维护通道已在用户这台机器的前序版本中验证；本独立 APK 完成了 14 项 shell 模拟场景、16 项兼容性/结果判断检查及 Android lint。独立 APK 的安装、遥控器导航、前台服务在厂商固件上的运行、异常中断恢复及重启后的默认桌面仍需实机测试。模拟检查不等于上述实机验证。

## 构建

JDK 17、Android SDK 34、Gradle 8.9、Android Gradle Plugin 8.5.2。
设置 JAVA_HOME、ANDROID_HOME 后执行 `./gradlew lintRelease assembleRelease`。
执行 `python3 tests/run_tests.py` 进行本机 shell/JVM 模拟检查。测试需要 POSIX 系统、Python 3 和 JDK 17。
